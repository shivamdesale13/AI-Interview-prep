🧠 AI-Powered Interview Preparation Platform
An interactive MERN stack application that helps users practice behavioral and technical interview questions. Includes AI-generated feedback, dark mode UI, and JWT-based authentication.

🚀 Features
🔐 User registration and login (JWT Auth)

🌗 Dark/light theme toggle

💬 AI feedback for behavioral questions (planned)

📊 Dashboard for performance analytics (planned)

🎯 Built using React, Node.js, Express, and MongoDB

🛠️ Tech Stack
Frontend: React.js, TailwindCSS, React Router

Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Auth: JWT, Bcrypt

Dev Tools: Vite, Postman, VS Code
